# 📖 Journal AI

**Journal AI** is a distraction-free, privacy-first markdown journaling application designed for mindful daily writing and self-reflection. It features real-time writing metrics, an interactive calendar with mood tracking, typography switching, dynamic 3-tier word count milestones (750w Morning Pages ➔ 1,400w Deep Flow ➔ 2,100w Masterpiece), and instant `.md` file export with structured YAML frontmatter.

The app provides multi-provider AI topic and emotion intelligence powered by Google Gemini, OpenAI, or private local Ollama models to automatically discover compound themes (e.g., `career · excited`) and granular subtopic tags (e.g., `#building-ai-app`, `#home-automation`). All data and API keys stay 100% client-side in your browser's local storage with zero server build steps—simply open `index.html` in any browser to begin writing.
